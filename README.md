# Deep Learning NLP Text Classifier

## Project Overview
This project classifies SMS messages as Spam or Ham
using a deep learning neural network built with PyTorch.

## Technologies Used
- Python
- PyTorch
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Implementation
1. Load and clean the SMS dataset.
2. Split the data into training and testing sets.
3. Convert text into numerical features using TF-IDF.
4. Build a multi-layer neural network.
5. Train the model with validation and early stopping.
6. Plot training and validation curves.
7. Evaluate the model on unseen test data.
8. Predict the class and confidence of new messages.
